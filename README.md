# DPTB2 Utils User Edition

A utility mod for the Hypixel Housing game **Don't Press The Button 2**.

This is a fork of DPTB2 Utils with additional HUD features and custom modifications.

## Supported Versions

* Fabric 1.21.4

## Features
* **/tima** command from [poo](https://github.com/mine-guy/dptb2-poo-1.2.2/tree/master)
* City door switch timer HUD
* Micro timer warning sound
* **/antitrafficlights** command, play warning sound 3 seconds before traffic light becomes red.

## Installation

### Download Release

Download the latest release from the repository's Releases page.

### Build From Source

Clone the repository and run:

```bash
./gradlew build
```

The compiled mod will be generated in:

```text
build/libs/
```
